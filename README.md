# Healthcare Survey Project

## Project Description

This project is a healthcare survey web application developed using Flask, MongoDB, Python, and Jupyter Notebook.

The application collects participant information including:

- Age
- Gender
- Total Income
- Expenses:
  - Utilities
  - Entertainment
  - School Fees
  - Shopping
  - Healthcare

The data is stored in MongoDB Atlas and exported to CSV for analysis.

## Technologies Used

- Python
- Flask
- MongoDB Atlas
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features

- Web form for collecting survey data
- MongoDB database storage
- CSV export
- Data visualization charts
- User class implementation
